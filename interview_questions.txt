1. What happens when you execute a Linux command?
Answer:

Example:

ls -l

Flow:

Shell receives the command.
Shell searches command in $PATH.
Creates a child process using fork().
Executes command using exec().
Kernel loads the program into memory.
Process executes.
Exit status is returned to shell.
2. Difference between Linux kernel and operating system?
Answer:

Kernel

Core part of OS.
Manages CPU, memory, devices, processes.

Operating System

Kernel + utilities + applications.

Example:

Linux kernel + GNU utilities = Linux OS.
